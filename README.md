# AVYOMA CRM — Enterprise B2B Defence, Aerospace & Engineering Platform

**AVYOMA CRM** is a production-ready, enterprise-grade Customer Relationship Management (CRM) module purpose-built for **AVYOMA SYSTEMS** across Defence, Aerospace, Precision Manufacturing, Heavy Engineering, and Industrial Technology sectors.

> *"Precision in Every Relationship."*

---

## 🌟 Key Functional Features

1. **Executive CRM Dashboard**:
   - 9 KPI Summary Cards (Total Leads, Qualified Leads, Open Deals, Pipeline Value ₹, Weighted Value ₹, Won Revenue ₹, Lost Deals, Conversion Rate, Upcoming Follow-ups).
   - Interactive Revenue Forecast Area Chart (Monthly & Quarterly).
   - Sales Conversion Funnel Visualization.
   - Pipeline Distribution by Industry Sector & Stage.
   - Owner Leaderboards & Lead Source Performance.
   - Follow-ups Today Widget & Overdue Task Reminders.

2. **Lead Management & Configurable Lead Scoring**:
   - Extended B2B Lead Metadata (Industry, Sector, Estimated Deal Value, Expected Purchase Timeline, Requirement Type).
   - Configurable Lead Scoring Engine (0-100 score calculating Cold/Warm/Hot/Very Hot badge indicators).
   - Lead Conversion Wizard (`Lead → Account + Primary Contact + Opportunity`).

3. **Kanban Sales Pipeline & Opportunity Management**:
   - 8 Pipeline Stages (`NEW` → `QUALIFICATION` → `DISCOVERY` → `TECHNICAL EVALUATION` → `PROPOSAL` → `NEGOTIATION` → `CONTRACT / PO` → `WON`).
   - Interactive Drag-and-Drop pipeline columns with real-time stage probability updates and weighted deal value (`Value × Probability`).
   - Mandatory Confirmation Dialogs for `WON` and `LOST` stages (with Loss Reason capture).

4. **Commercial Proposals & Quotation Generator**:
   - Line Item Builder auto-populated from Products & Services catalogue.
   - Real-time automatic calculations: Subtotal, Item Discounts, GST/Tax (18%), and Grand Total in INR (`₹`).
   - Official Printable & PDF-ready Quotation Preview Modal.

5. **B2B Defence & Aerospace Metadata**:
   - Tender Numbers, RFP/RFQ ID, Procurement Organization, End Customer, Security Classification (Public, Internal, Confidential, Highly Confidential), MIL-SPEC Compliance.

6. **Activities, Tasks & Follow-up System**:
   - Log Meetings, Calls, Demos, Site Visits, Technical Evaluation discussions.
   - Task Management with list and overdue view modes, priority badges, and one-click completion.

7. **Enterprise Security & Audit Trail**:
   - Role-Based Access Control (RBAC) with 7 defined roles (`Super Admin`, `Admin`, `Sales Manager`, `Sales Executive`, `Technical / Engineering`, `Finance`, `Viewer`).
   - Immutable System Audit Logs recording stage changes, proposal creation, lead conversion, and ownership updates.
   - Global Search Palette (`Ctrl + K` / `Cmd + K`) searching across all CRM entity types.

## 🛠️ Technology Stack

- **HTML5 & Semantic Structure**: Accessibility & WCAG compliance.
- **CSS3 (Vanilla CSS - AVYOMA PRECISION)**: Custom dark navy enterprise aesthetic (`#0B1220` primary canvas, `#080F1C` sidebar, `#F5F7FA` main background, cyan/electric blue `#2563EB` action accents, crisp 8px grid system, tabular numbers).
- **JavaScript (ES6+) & React 18**: Built with **Vite**.
- **Icons & Data Visualization**: Lucide React Icons & Recharts.
- **Data Layer & Persistence**: `LocalStorage` engine pre-seeded with realistic B2B Defence & Aerospace company data (HAL, BEL, L&T Defence, Dynamatic Technologies, TASL, Godrej Aerospace).

```bash
# 3. Build production bundle
npm run build
```
